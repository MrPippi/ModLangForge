# ModLangForge 繁中模組翻譯站

**Minecraft 模組的繁體中文（台灣用語）翻譯，一鍵下載資源包**

搜尋模組、下載翻譯好的資源包，或把多個模組的翻譯合成一個資源包一次下載。<br>
找不到想要的模組時，也可以直接在瀏覽器裡自己翻譯。

## 網站可以做什麼

- **搜尋模組**：輸入英文名稱、中文名稱或常見別名都找得到，例如「Create」、「機械動力」、「JEI」。
- **下載資源包**：在模組頁選擇你玩的 Minecraft 版本，網站會直接產生對應的資源包，舊版遊戲也能用。
- **合併資源包**：同時玩很多模組時，可以把它們加入「合併資源包」，一次下載一個資源包就好，不必一個一個安裝。
- **整合包**：「整合包」頁面列出各整合包用到的模組和翻譯完成度，可以一次下載整合包裡所有已翻譯模組的資源包，也包含整合包自己加的文字（KubeJS）；Minecraft 1.21 以上的整合包還會附上 FTB 任務的翻譯，下載後解壓縮到整合包資料夾即可。
- **自己翻譯**：網站還沒收錄的模組，可以到「自己翻譯」頁面把模組檔（`.jar`）拖進網頁翻譯，完成後直接做成資源包。檔案只在你的電腦上處理，不會上傳；翻到一半的進度也會自動保存。

全部功能都免費，不需要註冊或登入。

## 怎麼使用

1. 開啟 [modlangforge.com](https://modlangforge.com)，搜尋模組並進入模組頁。
2. 選擇你玩的 Minecraft 版本，下載資源包（`.zip` 檔，不用解壓縮）。
3. 把資源包放進遊戲的 `resourcepacks` 資料夾。
4. 進入遊戲，在「選項 → 資源包」中啟用它，並把語言設為「繁體中文（台灣）」。

想一次使用多個模組的翻譯：在各模組頁按「加入合併資源包」，再到「合併資源包」頁面選擇版本、下載一個資源包即可。合併資源包的清單只保存在你目前使用的瀏覽器裡，換裝置或清除瀏覽資料後需要重新加入。

## 常見問題

**放進資源包了，遊戲裡還是英文？**

請依序確認：

1. 資源包已經在「選項 → 資源包」中啟用（出現在右側「已選取」的清單裡）。
2. 遊戲語言設為「繁體中文（台灣）」。
3. 下載時選擇的 Minecraft 版本和你玩的版本相同。
4. 如果同時裝了其他中文資源包，把本站的資源包拖到清單較上方，上方的資源包會優先套用。

**翻譯是人工翻的嗎？**

很多模組目前是機器自動翻譯的。模組頁會標示翻譯狀態：「由機器自動翻譯，還沒有人檢查過」、「有一部分已經有人檢查過」或「全部都有人檢查過」。看到不通順的地方，歡迎[幫忙修正](#幫忙改善翻譯)。

**模組更新了，翻譯也會更新嗎？**

網站每週會自動檢查已收錄模組的新版本，並補上新增的文字。模組更新後，重新下載一次資源包，就能拿到最新的翻譯。剛新增的文字可能還沒翻譯，會先顯示英文。

**我想要的模組沒有收錄？**

可以先到「自己翻譯」頁面自己動手翻，或到 GitHub [提出翻譯需求](https://github.com/MrPippi/ModLangForge/issues/new)，請大家一起幫忙。

**資源包安全嗎？**

資源包裡只有翻譯文字，不包含任何程式或模組檔案。使用「自己翻譯」時，你的模組檔也只在自己的電腦上處理，不會上傳到任何地方。

## 幫忙改善翻譯

- **建議修改譯文**：在模組頁按譯文旁的「建議修改」，或用「搜尋這個模組的所有文字」找到想改的句子後送出。不登入也可以送出，只需要通過一個簡單的人機驗證。
- **登入並署名**：用 Discord 或 GitHub 帳號登入後，你送出的建議通過審核時，會在「貢獻者」頁面署名。你也可以在個人頁面設定顯示名稱、選擇是否公開署名、填寫 Minecraft 玩家名稱，以及查看自己送出過的建議。
- **審核與更新**：維護者審核通過後，新的譯文會在幾分鐘內出現在網站上。
- **貢獻者排行**：「貢獻者」頁面會依照已採用的譯文數量，列出選擇公開署名的貢獻者。

想新增模組或了解翻譯原則，請參考[貢獻指南](./CONTRIBUTING.md)。

## 給模組作者：移除申請

感謝你製作了這些模組！如果你是模組作者或著作權人，不希望本站收錄你的模組原文或譯文，歡迎直接告訴我們：

1. 到 GitHub [開一個 issue](https://github.com/MrPippi/ModLangForge/issues/new)。
2. 寫明模組名稱，以及希望移除的範圍（部分文字、譯文，或整個模組）。

我們收到後會儘快處理並移除，不需要任何正式文件。
