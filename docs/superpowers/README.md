# 開發設計紀錄

這個資料夾保存 ModLangForge 開發過程中的設計規格（`specs/`）與實作計畫（`plans/`），主要給維護者回顧當初為什麼這樣設計。

閱讀前請留意：

- 這些是**當時的紀錄**，寫成之後程式可能又改過，內容不一定與目前的程式碼相符。
- 文件是寫給開發時使用的，用語偏技術、也較精簡，不是使用說明。
- 想了解網站怎麼用，請看[專案首頁說明](../../README.md)；想參與翻譯或開發，請看[貢獻指南](../../CONTRIBUTING.md)。

為了讓過去 Pull Request 裡的連結繼續有效，這些檔案會保留在原位置，不另外搬移或改寫。
