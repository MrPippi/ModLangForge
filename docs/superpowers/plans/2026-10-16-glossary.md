# 術語表與跨模組一致性檢查 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 新增全域與模組術語表，`validate:data` 檢查譯文是否使用規定譯名，提供探勘報告工具，並在 translator 每列顯示術語提示。

**Architecture:** 比對、檢查、合併、檔案驗證、探勘都是 `packages/core/src/glossary/` 的純函式；`loadAllMods` 讀取術語檔並把合併後的術語交給 `validateModData`；網站以靜態端點 `/api/v1/glossary.json` 輸出術語，translator 載入一次後在 `TranslationRow` 顯示提示。

**Tech Stack:** TypeScript、zod 4、Vitest（core: node；site: jsdom＋Testing Library）、Astro 7 靜態端點、React 18、Playwright（wrangler dev）。

**Spec:** `docs/superpowers/specs/2026-10-16-glossary-design.md`

## Global Constraints

- 全域術語檔：`data/glossary.json`；模組術語檔：`data/mods/<modId>/glossary.json`（選填）。兩者格式 `{ "terms": GlossaryTerm[] }`。
- 全域術語檔不存在時視為 `{ "terms": [] }`（spec 已同步修訂）。
- `level` 預設 `"warning"`；`"error"` 時違規讓 `validate:data` 失敗。
- 全域術語檔問題以 modId `(glossary)`（常數 `GLOBAL_GLOSSARY_ID`）回報，GitHub 註記路徑為 `data/glossary.json`。
- 違規訊息格式：`術語「<en>」應譯為「<zh>」`，檔案 `zh_tw.json`，附 key。
- 比對：不分大小寫、整字邊界（前後不得緊鄰英數字或底線；用 lookaround 實作，因 `\b` 遇到以 `+`、`)` 結尾的術語會失效）、多字詞間任意空白、最後一字可加 `s`／`es`、長詞優先、同條目同術語只回報一次。
- 略過：譯文為空白字串，或譯文與原文完全相同。
- 模組表覆蓋全域表：以 `en.toLowerCase()` 為鍵。
- 靜態端點：`/api/v1/glossary.json` → `{ version: 1, global: GlossaryTerm[], mods: Record<modId, GlossaryTerm[]> }`，`mods` 只含有模組表者；`Cache-Control: public, max-age=300`。
- translator 術語載入失敗：不顯示提示，`console.error`，翻譯功能不受影響。
- 不可變：所有函式回傳新陣列／物件，不修改輸入。
- 初版全域術語（皆 `warning`）：Enchantment→附魔、Redstone→紅石、Nether→地獄、Inventory→物品欄、Biome→生態域、Recipe→配方、Config→設定、Bookmark→書籤、Waypoint→路徑點、Minimap→小地圖。Create 模組術語：Cogwheel→齒輪、Shaft→傳動軸。

## Review Focus

1. 術語含正規表示式特殊字元（`C++`、`Wand (Iron)`）→ 正確跳脫，不拋錯、不誤配。（Task 2 測試）
2. 全域術語檔不存在 → 無任何 issue，術語為空。（Task 4 測試）
3. translator 查詢 modId 為 `constructor`／`__proto__` → 只回傳全域術語，不取到原型屬性。（Task 7 測試）
4. 譯文以較長詞包含規定譯名（「設定檔」含「設定」）→ 視為已使用，不回報。（Task 2 測試）
5. 大型專案（上千列）每次渲染都跑比對 → 每個術語的正規表示式只編譯一次（`WeakMap` 快取）。（Task 2 實作）

```ts
import type { GlossaryTerm } from './schema';

const keyOf = (t: GlossaryTerm): string => t.en.toLowerCase();

/** 模組術語覆蓋同名（不分大小寫）的全域術語並保留其位置，模組獨有的術語附加在後 */
export function mergeGlossaries(global: readonly GlossaryTerm[], mod: readonly GlossaryTerm[]): GlossaryTerm[] {
  const overrides = new Map(mod.map((t) => [keyOf(t), t] as const));
  const globalKeys = new Set(global.map(keyOf));
  return [...global.map((t) => overrides.get(keyOf(t)) ?? t), ...mod.filter((t) => !globalKeys.has(keyOf(t)))];
}
```

```ts
import type { GlossaryTerm } from './schema';

interface Hit {
  readonly term: GlossaryTerm;
  readonly start: number;
  readonly end: number;
}

const escapeRegExp = (s: string): string => s.replace(/[.*+?^${}()|[\]\\]/g, '\\$&');

/** 每個術語的正規表示式只編譯一次；matchAll 會複製 regex，重複使用安全 */
const patterns = new WeakMap<GlossaryTerm, RegExp>();

function patternOf(term: GlossaryTerm): RegExp {
  const cached = patterns.get(term);
  if (cached) return cached;
  const words = term.en.split(/\s+/).map(escapeRegExp);
  const pattern = new RegExp(`(?<![\\w])${words.join('\\s+')}(?:e?s)?(?![\\w])`, 'gi');
  patterns.set(term, pattern);
  return pattern;
}

function hitsOf(source: string, term: GlossaryTerm): Hit[] {
  return [...source.matchAll(patternOf(term))].map((m) => ({ term, start: m.index ?? 0, end: (m.index ?? 0) + m[0].length }));
}

const coveredBy = (inner: Hit, outer: Hit): boolean =>
  outer.start <= inner.start && inner.end <= outer.end && outer.end - outer.start > inner.end - inner.start;

/** 回傳原文命中的術語：不分大小寫、整字比對、最後一字可加 s/es，較長命中覆蓋其內的較短命中；依首次出現排序並去重 */
export function findTerms(source: string, terms: readonly GlossaryTerm[]): GlossaryTerm[] {
  const hits = terms.flatMap((t) => hitsOf(source, t));
  const kept = hits.filter((h) => !hits.some((o) => coveredBy(h, o))).sort((a, b) => a.start - b.start);
  return [...new Set(kept.map((h) => h.term))];
}
```

（用 `(?<![\w])`／`(?![\w])` 而非 `\b`：術語以 `+`、`)` 等非字元結尾時 `\b` 會失效。）

```ts
import { findTerms } from './match';
import type { GlossaryLevel, GlossaryTerm } from './schema';

export interface GlossaryIssue {
  readonly term: GlossaryTerm;
  readonly level: GlossaryLevel;
}

/** 原文命中術語但譯文不含規定譯名時回報；譯文空白或與原文相同（未翻譯）時不檢查 */
export function checkGlossary(source: string, target: string, terms: readonly GlossaryTerm[]): GlossaryIssue[] {
  if (target.trim() === '' || target === source) return [];
  return findTerms(source, terms)
    .filter((t) => !target.includes(t.zh))
    .map((term) => ({ term, level: term.level }));
}
```

```ts
import { glossaryFileSchema, type GlossaryTerm } from './schema';

export type GlossaryFileResult =
  | { readonly ok: true; readonly terms: readonly GlossaryTerm[] }
  | { readonly ok: false; readonly messages: readonly string[] };

/** 驗證術語檔內容：schema 與同檔英文詞重複（不分大小寫） */
export function validateGlossaryFile(raw: unknown): GlossaryFileResult {
  const parsed = glossaryFileSchema.safeParse(raw);
  if (!parsed.success) {
    return { ok: false, messages: parsed.error.issues.map((i) => `${i.path.join('.') || '(root)'}：${i.message}`) };
  }
  const keys = parsed.data.terms.map((t) => t.en.toLowerCase());
  const dupes = parsed.data.terms.filter((_, i) => keys.indexOf(keys[i]!) !== i).map((t) => `術語「${t.en}」重複`);
  return dupes.length > 0 ? { ok: false, messages: dupes } : { ok: true, terms: parsed.data.terms };
}
```

```ts
import { checkGlossary } from './check';
import type { GlossaryTerm } from './schema';

export interface MineEntry {
  readonly modId: string;
  readonly key: string;
  readonly source: string;
  readonly target: string;
}

export interface Variant {
  readonly target: string;
  readonly refs: readonly string[];
}

export interface Candidate {
  readonly en: string;
  readonly modCount: number;
  readonly variants: readonly Variant[];
}

export interface TermViolations {
  readonly term: GlossaryTerm;
  readonly count: number;
  readonly refs: readonly string[];
}

const MAX_WORDS = 3;
const MAX_REFS = 5;

const refOf = (e: MineEntry): string => `${e.modId}:${e.key}`;
const isTranslated = (e: MineEntry): boolean => e.target.trim() !== '' && e.target !== e.source;
const isShort = (e: MineEntry): boolean => e.source.trim().split(/\s+/).length <= MAX_WORDS;

function groupBy<T>(items: readonly T[], keyOf: (item: T) => string): Map<string, T[]> {
  return items.reduce((map, item) => {
    const key = keyOf(item);
    return map.set(key, [...(map.get(key) ?? []), item]);
  }, new Map<string, T[]>());
}

/** 找出英文原文相同（1–3 個單字、不分大小寫）但譯法不只一種的條目群組，依涉及模組數排序 */
export function findCandidates(entries: readonly MineEntry[]): Candidate[] {
  const groups = groupBy(entries.filter((e) => isTranslated(e) && isShort(e)), (e) => e.source.trim().toLowerCase());
  return [...groups.entries()]
    .map(([en, list]) => ({
      en,
      modCount: new Set(list.map((e) => e.modId)).size,
      variants: [...groupBy(list, (e) => e.target).entries()].map(([target, items]) => ({ target, refs: items.map(refOf) })),
    }))
    .filter((c) => c.variants.length >= 2)
    .sort((a, b) => b.modCount - a.modCount || a.en.localeCompare(b.en));
}

/** 統計每個術語的違規次數（以各模組合併後的術語檢查），違規多者在前 */
export function countViolations(entries: readonly MineEntry[], termsFor: (modId: string) => readonly GlossaryTerm[]): TermViolations[] {
  const hits = entries.flatMap((e) => checkGlossary(e.source, e.target, termsFor(e.modId)).map(({ term }) => ({ term, ref: refOf(e) })));
  return [...groupBy(hits, (h) => `${h.term.en.toLowerCase()}\u0000${h.term.zh}`).values()]
    .map((list) => ({ term: list[0]!.term, count: list.length, refs: list.slice(0, MAX_REFS).map((h) => h.ref) }))
    .sort((a, b) => b.count - a.count || a.term.en.localeCompare(b.term.en));
}

export function renderMineReport(candidates: readonly Candidate[], violations: readonly TermViolations[]): string {
  const candidateLines = candidates.length === 0
    ? ['沒有譯法不一致的候選。']
    : candidates.flatMap((c) => [
      `### ${c.en}（${c.modCount} 個模組）`,
      ...c.variants.map((v) => `- ${v.target}：${v.refs.slice(0, MAX_REFS).join('、')}`),
      '',
    ]);
  const violationLines = violations.length === 0
    ? ['沒有術語違規。']
    : violations.map((v) => `- ${v.term.en} → ${v.term.zh}：${v.count} 次（${v.refs.join('、')}）`);
  return ['# 術語探勘報告', '', '## 譯法不一致候選', '', ...candidateLines, '', '## 現有術語違規', '', ...violationLines, ''].join('\n');
}
```

```ts
  readonly mods: readonly SiteMod[];

let cache: Promise<SiteData> | null = null;

async function load(): Promise<SiteData> {
  const { mods, issues, glossary } = await loadAllMods(DATA_DIR);
  const errors = issues.filter((i) => i.level === 'error');

export interface GlossaryPayload {

  readonly mods: Readonly<Record<string, readonly GlossaryTerm[]>>;
```

```ts
import { z } from 'zod';
import { glossaryTermSchema, type GlossaryTerm, mergeGlossaries } from '@mlf/core/glossary';

export const GLOSSARY_URL = '/api/v1/glossary.json';

const payloadSchema = z.object({
  version: z.literal(1),
  global: z.array(glossaryTermSchema),
  mods: z.record(z.string(), z.array(glossaryTermSchema)),
});

/** 依 modId 取得合併後（模組覆蓋全域）的術語 */
export type GlossaryLookup = (modId: string) => readonly GlossaryTerm[];

export async function fetchGlossary(signal?: AbortSignal, fetchImpl: typeof fetch = fetch): Promise<GlossaryLookup> {
  const res = await fetchImpl(GLOSSARY_URL, { signal });
  if (!res.ok) throw new Error(`Glossary HTTP ${res.status}`);
  const data = payloadSchema.parse(await res.json());
  const cache = new Map<string, readonly GlossaryTerm[]>();
  return (modId) => {
    const cached = cache.get(modId);
    if (cached) return cached;
    const modTerms = Object.hasOwn(data.mods, modId) ? data.mods[modId]! : [];
    const terms = mergeGlossaries(data.global, modTerms);
    cache.set(modId, terms);
    return terms;
  };
}
```

```ts
import { useEffect, useState } from 'react';
import { fetchGlossary, type GlossaryLookup } from './glossaryClient';

/** 載入術語表一次；失敗時維持 null（不顯示提示）並記錄錯誤。load 必須是穩定參考 */
export function useGlossary(load: (signal: AbortSignal) => Promise<GlossaryLookup> = fetchGlossary): GlossaryLookup | null {
  const [lookup, setLookup] = useState<GlossaryLookup | null>(null);
  useEffect(() => {
    const controller = new AbortController();
    load(controller.signal).then(
      (fn) => {
        if (!controller.signal.aborted) setLookup(() => fn);
      },
      (err: unknown) => {
        if (!controller.signal.aborted) console.error('[translator] 術語表載入失敗', err);
      },
    );
    return () => controller.abort();
  }, [load]);
  return lookup;
}
```
