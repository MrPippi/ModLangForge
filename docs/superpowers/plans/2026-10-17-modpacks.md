# 整合包翻譯（含 KubeJS）Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 讓整合包（Modrinth `.mrpack`／CurseForge `.zip`）以 `data/modpacks/<id>/` 收錄進網站：維護者用 `add:modpack` 腳本新增或更新；網站有整合包目錄、整合包頁與 API，可一鍵下載「已收錄模組（含手冊）＋ KubeJS 譯文」的合併資源包；翻譯工具可載入網站上的整合包翻譯 KubeJS 文字並匯出。

**Architecture:** `packages/core/src/modpack/` 是純函式：`catalogModpackSchema`（zod）、slug 對照（`resolveModpackMods`）、`modpack.json`／KubeJS 驗證、KubeJS 命名空間轉成 `ModProject`（`modId` = 命名空間、`id` = `modpack:<id>:<ns>`），因此資源包輸出直接沿用 `exportProjects` 的 `assets/<modId>/lang/zh_tw.json`；`exportProjects` 先以 `mergeSameNamespace` 把同命名空間的專案合成一份，避免 KubeJS 與模組同名時互相覆蓋。`packages/core/src/modpackImport/` 負責腳本邏輯：壓縮檔解析（`modrinth.index.json`／`manifest.json`／`overrides/kubejs/assets/<ns>/lang/en_us.json`）、以注入的 `FetchLike` 呼叫 Modrinth 與 CurseForge、`planModpackWrite`（沿用 `addSourceVersion` 的衝突規則）與 `runAddModpack`（注入 IO）；`scripts/add-modpack.ts` 只提供真實 fetch、`.env` 與檔案讀寫。`packages/core/src/node/loadModpacks.ts` 讀取並驗證 `data/modpacks/`，`validate:data` 與網站建置共用；網站在建置時對照模組、計算進度、輸出 API，下載在瀏覽器內以既有 `fetchModData` ＋ `exportProjects` 完成。

**Tech Stack:** TypeScript、zod 4、JSZip、Vitest（core: node；site: jsdom＋Testing Library＋fake-indexeddb）、Astro 7、React 18、zustand、Playwright（wrangler dev）、tsx（腳本）。

**Spec:** docs/superpowers/specs/2026-10-17-modpacks-design.md

## Global Constraints

- 資料位置：`data/modpacks/<id>/modpack.json`、`data/modpacks/<id>/kubejs/<ns>/en_us.json`（英文原文）、選填 `data/modpacks/<id>/kubejs/<ns>/zh_tw.json`（譯文）；一個整合包可有多個命名空間。
- `<id>` 規則同模組 modId（`^[a-z0-9_.-]+$`，且不可為 `.`／`..`）；`<ns>` 規則同 jar 命名空間（`^[a-z0-9_.-]+$`，且不可為 `.`／`..`）。
- `modpack.json` 欄位：`id`、`name`、選填 `nameZh`、`summary`（≤120 字）、`authors`、`links`（至少一個）、`source`、`mods`、`translation`、`updatedAt`（YYYY-MM-DD）。
- `source.platform` 為 `modrinth` 或 `curseforge`；`source.mcVersion` 必須在 `PACK_FORMATS` 中；`source.loader` 沿用 `LOADERS`；`translation` 沿用模組的格式與授權選項（`TRANSLATION_STATUSES`、`LICENSE_ALLOWLIST`）。
- `mods` 為整合包使用的模組（`platform`、`projectId`、`slug`），`(platform, projectId)` 不可重複。
- 不存 modId：網站建置時以 slug 對照各模組 `mod.json` 的 `links.modrinth`（`https://modrinth.com/mod/<slug>`）或 `links.curseforge`（`https://www.curseforge.com/minecraft/mc-mods/<slug>`）；之後新收錄的模組自動對上。
- 指令：`npm run add:modpack -- --modrinth <slug|id>` 或 `npm run add:modpack -- --curseforge <slug|id>`，另可 `--version <版本號>`（預設最新）；CurseForge 無 `downloadUrl` 時以清楚訊息結束，請維護者以 `--file <path>` 提供檔案。
- Modrinth：`/v2/project/<slug>`、`/v2/project/<id>/version`，下載 `.mrpack`；讀 `modrinth.index.json` 的 `dependencies`（MC 版本、載入器）與 `files[].downloads`，由 `https://cdn.modrinth.com/data/<projectId>/…` 取得專案 ID，再以 `/v2/projects?ids=[…]` 批次查 slug。
- CurseForge：讀 `CURSEFORGE_API_KEY`（未設定時印出設定方式並以非 0 結束；專案根目錄有 `.env` 則先載入），以 `x-api-key` 呼叫 `api.curseforge.com/v1`（gameId 432、整合包分類 classId 4471）；讀 `manifest.json` 的 `minecraft.version`、`minecraft.modLoaders` 與 `files[].projectID`，以 `POST /v1/mods` 批次查 slug。
- KubeJS 只讀 `overrides/kubejs/assets/<ns>/lang/en_us.json`。
- 新增：建立 `modpack.json`（簡介為佔位文字 `SUMMARY_PLACEHOLDER`、`translation.status` 為 `machine`）與 `kubejs/<ns>/en_us.json`。
- 更新（目錄已存在）：更新 `source` 與 `mods`（另併入平台連結、`updatedAt`）；KubeJS 英文以聯集合併（新 key 加入、原文不同列為差異且保留既有原文、格式碼改變則拒絕寫入任何檔案）；不動 `zh_tw.json`。
- 金鑰：只來自環境變數 `CURSEFORGE_API_KEY` 或 worktree 根目錄 `.env`（已被 `.gitignore`）；只在 Node 腳本使用、只送往 `api.curseforge.com`（不送往下載 CDN）；不寫入任何檔案、不印出、不出現在網站或瀏覽器程式碼、程式碼、測試、fixture、log、commit。測試一律注入假 fetch 與假金鑰字串。
- 本計畫任何步驟都不對網路執行真實的 `add:modpack`，也不提交真實整合包資料；E2E 用測試專用的範例整合包 `data/modpacks/example-pack/`（沿用 `data/mods/examplelegacy` 的範例資料慣例，簡介標明不對應真實整合包）。
- 驗證（`validate:data`）：`modpack.json` 不符 schema、資料夾名稱與 `id` 不一致 → error；KubeJS 語言檔頂層不是字串物件 → error；`zh_tw.json` 的 key 不在 `en_us.json` → error；格式碼不一致 → warning；術語表套用 → 依術語 level；以 `data/modpacks/<id>/…` 路徑回報 GitHub 註記；有 error 的整合包不出現在網站（建置不中斷）。
- 網站：頁首導覽新增「整合包」；`/modpacks/` 列出名稱、中文名、MC 版本、載入器、「已收錄模組 N／M」、KubeJS 進度；`/modpacks/<id>/` 有基本資料與平台連結、已收錄模組（完成度＋連到模組頁）與未收錄模組（slug＋平台連結）、KubeJS 翻譯進度（各命名空間合計）、一鍵下載。
- 一鍵下載：合併資源包內含所有已收錄模組的翻譯（含手冊）與 KubeJS 譯文（`assets/<ns>/lang/zh_tw.json`）；`pack_format` 依 `source.mcVersion`；未翻譯的條目保留英文；檔名 `<id>-zh_tw-<mcVersion>.zip`。
- API：`/api/v1/modpacks/index.json`（`{ version: 1, generatedAt, modpacks: ModpackSummary[] }`）、`/api/v1/modpacks/<id>.json`（`{ version: 1, meta, mods（含對照後 modId，未收錄為 null）, kubejs: { <ns>: { en_us, zh_tw } } }`）。
- 翻譯工具：「載入網站上的整合包」由 `/api/v1/modpacks/<id>.json` 讀出 KubeJS 文字，每個命名空間一個專案，專案 ID `modpack:<id>:<ns>`、顯示名稱「<整合包名>（KubeJS：<ns>）」；重新載入同一整合包時套用與模組相同的合併規則（`mergeProject`）；資源包輸出 `assets/<ns>/lang/zh_tw.json`；貢獻檔輸出 `modpacks/<id>/kubejs/<ns>/zh_tw.json` 與說明。
- 不在範圍：FTB Quests（4c）、每週自動追蹤整合包新版本、投稿者在翻譯工具上傳新整合包、KubeJS 以外的整合包文字（`resourcepacks/`、OpenLoader、`config/`）、模組 jar 的自動收錄。
- 網站文字：台灣繁中、玩家看得懂的說法（modpack＝整合包；本站合併功能叫「合併資源包」）；使用既有語意色彩 token（`text-muted`、`text-warn`、`text-danger`、`border-line`、`bg-warn-soft`…）。
- 不可變：所有函式回傳新物件／陣列，不修改輸入；檔案 200–400 行為主、最多 800 行；所有外部資料（API 回應、壓縮檔內容、`data/` 檔案、站內 API payload）以 zod 或既有驗證函式驗證。
- TDD：每個 task 先寫失敗的測試、執行並記錄 RED，再實作到 PASS。core 覆蓋率（`npm run test:coverage -w @mlf/core`）維持 ≥ 80%。
- Commit：英文 Conventional Commits；絕不加 `Claude-Session` trailer、`Co-Authored-By` 或任何 claude.ai 連結。PR 說明用台灣繁中，只寫「摘要」「變更內容」（「備註」選填），不列測試、不附 session 連結（CONTRIBUTING「Pull Request 規範」）。
- 換行：repo 檔案一律 LF。每次 commit 前確認 `git diff --cached --stat` 與 `git diff --cached --ignore-cr-at-eol --stat` 輸出相同（不同代表寫入了 CRLF，先轉回 LF）。

## Review Focus

1. KubeJS 命名空間與已收錄模組的 modId 相同（例如整合包在 `create` 命名空間加文字）→ 資源包只有一份 `assets/create/lang/zh_tw.json`，模組譯文與 KubeJS 譯文都在、同 key 以 KubeJS 為準，不會互相覆蓋。（Task 5 `mergeSameNamespace` 測試；Task 13 `merges KubeJS text into a mod namespace with the same name`）
2. 壓縮檔或站內 payload 帶有危險／不合法的命名空間（`../evil`、`..`、`KubeJS`、空白）→ 壓縮檔中直接忽略、payload 驗證失敗；絕不寫到 `data/modpacks/<id>/kubejs/<ns>/` 或 `assets/<ns>/lang/` 之外。（Task 6 `extracts KubeJS English per valid namespace`；Task 13 `rejects namespaces that could escape assets/<ns>/lang/`）
3. CurseForge 金鑰外洩：金鑰只放在送往 `https://api.curseforge.com/v1` 的 `x-api-key` 標頭，下載 CDN 請求沒有金鑰；任何錯誤訊息中的金鑰以「[已隱藏]」取代，寫入的檔案不含金鑰。（Task 9 `sends the key only to the CurseForge API`；Task 10 `redacts the key from errors and never writes it`）
4. 翻譯工具中已載入整合包命名空間 `kubejs`，再上傳一個命名空間也是 `kubejs` 的 jar → 兩者是不同專案、不跳出「模組已存在」對話框、整合包專案不被覆蓋。（Task 14 `keeps jar mods and KubeJS namespaces with the same name apart`）
5. slug 對照的邊界：`mod.json` 連結有結尾斜線或大寫、兩個模組連到同一 slug、模組只有另一個平台的連結、整合包清單含資源包（CurseForge classId ≠ 6）或非 Modrinth CDN 的檔案 → 不分大小寫比對、同 slug 固定取 modId 排序最前者、不跨平台對照（列為未收錄）、非模組專案與外部檔案不進 `mods` 並列在腳本提示中。（Task 2 `resolveModpackMods` 測試；Task 6 `unknownFiles`；Task 9 `略過非模組專案`）

```ts
import { z } from 'zod';
import { modrinthSlug } from '../pipeline/modrinth';
import { type ModpackMod, modpackModSchema, type ModpackPlatform } from './schema';

const CURSEFORGE_MOD_URL = /^https:\/\/www\.curseforge\.com\/minecraft\/mc-mods\/([^/?#]+)\/?$/;

export function curseforgeSlug(url: string | undefined): string | null {
  return url?.match(CURSEFORGE_MOD_URL)?.[1] ?? null;
}

/** 平台上的模組頁 */
export function platformModUrl(m: Pick<ModpackMod, 'platform' | 'slug'>): string {
  const slug = encodeURIComponent(m.slug);
  return m.platform === 'modrinth' ? `https://modrinth.com/mod/${slug}` : `https://www.curseforge.com/minecraft/mc-mods/${slug}`;
}

/** 平台上的整合包頁 */
export function platformModpackUrl(platform: ModpackPlatform, slug: string): string {
  const encoded = encodeURIComponent(slug);
  return platform === 'modrinth' ? `https://modrinth.com/modpack/${encoded}` : `https://www.curseforge.com/minecraft/modpacks/${encoded}`;
}

/** 對照用的模組資料（mod.json 的 modId 與 links） */
export interface CatalogModLinks {
  readonly modId: string;
  readonly links: { readonly modrinth?: string; readonly curseforge?: string };
}

export const resolvedModpackModSchema = modpackModSchema.extend({ modId: z.string().nullable() });

/** 整合包使用的模組＋對照到的本站 modId（未收錄為 null） */
export type ResolvedModpackMod = z.infer<typeof resolvedModpackModSchema>;

const SLUG_OF: Readonly<Record<ModpackPlatform, (links: CatalogModLinks['links']) => string | null>> = {
  modrinth: (links) => modrinthSlug(links.modrinth),
  curseforge: (links) => curseforgeSlug(links.curseforge),
};

function slugIndex(catalog: readonly CatalogModLinks[], platform: ModpackPlatform): ReadonlyMap<string, string> {
  const sorted = [...catalog].sort((a, b) => (a.modId < b.modId ? -1 : a.modId > b.modId ? 1 : 0));
  const index = new Map<string, string>();
  for (const mod of sorted) {
    const slug = SLUG_OF[platform](mod.links)?.toLowerCase();
    if (slug && !index.has(slug)) index.set(slug, mod.modId);
  }
  return index;
}

/**
 * 以平台 slug 對照已收錄模組。slug 不分大小寫；不跨平台對照；
 * 多個模組連到同一 slug 時取 modId 排序最前者，結果固定。
 */
export function resolveModpackMods(mods: readonly ModpackMod[], catalog: readonly CatalogModLinks[]): ResolvedModpackMod[] {
  const indexes: Readonly<Record<ModpackPlatform, ReadonlyMap<string, string>>> = {
    modrinth: slugIndex(catalog, 'modrinth'),
    curseforge: slugIndex(catalog, 'curseforge'),
  };
  return mods.map((m) => ({ ...m, modId: indexes[m.platform].get(m.slug.toLowerCase()) ?? null }));
}

/** 已對上的 modId（去除重複，保留整合包中的順序） */
export function includedModIds(resolved: readonly ResolvedModpackMod[]): string[] {
  return [...new Set(resolved.flatMap((m) => (m.modId === null ? [] : [m.modId])))];
}
```

```ts
import { formatIssueMessage } from '../catalog/validateMod';
import { checkGlossary } from '../glossary/check';
import type { GlossaryTerm } from '../glossary/schema';
import { checkFormat } from '../validate/formatCodes';
import { catalogModpackSchema, isValidNamespace } from './schema';

export const MODPACK_FILE = 'modpack.json';
export const KUBEJS_DIR = 'kubejs';
export const KUBEJS_EN_FILE = 'en_us.json';
export const KUBEJS_ZH_FILE = 'zh_tw.json';

export interface ModpackIssue {
  readonly level: 'error' | 'warning';
  /** 相對整合包資料夾的路徑 */
  readonly file: 'modpack.json' | `kubejs/${string}`;
  readonly key?: string;
  readonly message: string;
}

export function kubejsFile(ns: string, name: string): ModpackIssue['file'] {
  return `kubejs/${ns}/${name}`;
}

function isPlainObject(value: unknown): value is Record<string, unknown> {
  return value !== null && typeof value === 'object' && !Array.isArray(value);
}

function recordIssues(file: ModpackIssue['file'], value: unknown): ModpackIssue[] {
  if (!isPlainObject(value)) return [{ level: 'error', file, message: '語言檔頂層必須是物件' }];
  return Object.entries(value)
    .filter(([, v]) => typeof v !== 'string')
    .map(([key]): ModpackIssue => ({ level: 'error', file, key, message: '值必須是字串' }));
}

/** 驗證 modpack.json；dirName 為資料夾名稱 */
export function validateModpackMeta(dirName: string, raw: unknown): ModpackIssue[] {
  const parsed = catalogModpackSchema.safeParse(raw);
  if (!parsed.success) {
    return parsed.error.issues.map((i): ModpackIssue => ({
      level: 'error',
      file: MODPACK_FILE,
      message: `${i.path.join('.') || '(root)'}：${i.message}`,
    }));
  }
  if (parsed.data.id !== dirName) {
    return [{ level: 'error', file: MODPACK_FILE, message: `id「${parsed.data.id}」與資料夾名稱「${dirName}」不一致` }];
  }
  return [];
}

function translationIssues(file: ModpackIssue['file'], en: Record<string, string>, zh: Record<string, string>, terms: readonly GlossaryTerm[]): ModpackIssue[] {
  return Object.entries(zh).flatMap(([key, target]): ModpackIssue[] => {
    const source = Object.hasOwn(en, key) ? en[key] : undefined;
    if (source === undefined) return [{ level: 'error', file, key, message: 'en_us.json 中沒有此 key' }];
    const format = checkFormat(source, target);
    const formatIssues: ModpackIssue[] = format ? [{ level: 'warning', file, key, message: formatIssueMessage(format) }] : [];
    const termIssues = checkGlossary(source, target, terms).map(({ term, level }): ModpackIssue => ({
      level, file, key, message: `術語「${term.en}」應譯為「${term.zh}」`,
    }));
    return [...formatIssues, ...termIssues];
  });
}

/** 驗證一個 KubeJS 命名空間；zh 為 zh_tw.json 的內容（不存在時傳 {}）；回傳空陣列代表完全合法 */
export function validateKubejsData(ns: string, en: unknown, zh: unknown, terms: readonly GlossaryTerm[] = []): ModpackIssue[] {
  if (!isValidNamespace(ns)) {
    return [{ level: 'error', file: `kubejs/${ns}`, message: '命名空間只能包含 a-z 0-9 _ . -，且不可為 . 或 ..' }];
  }
  const zhFile = kubejsFile(ns, KUBEJS_ZH_FILE);
  const base = [...recordIssues(kubejsFile(ns, KUBEJS_EN_FILE), en), ...recordIssues(zhFile, zh)];
  if (base.some((i) => i.level === 'error')) return base;
  return translationIssues(zhFile, en as Record<string, string>, zh as Record<string, string>, terms);
}
```

```ts
import type { Dirent } from 'node:fs';
import { readdir, readFile } from 'node:fs/promises';
import { join } from 'node:path';
import type { GlossaryTerm } from '../glossary/schema';
import { stripBom } from '../lang/types';
import { type CatalogModpack, catalogModpackSchema, isValidNamespace } from '../modpack/schema';
import type { KubejsData, KubejsTexts } from '../modpack/types';
import {
  KUBEJS_DIR, KUBEJS_EN_FILE, KUBEJS_ZH_FILE, kubejsFile, MODPACK_FILE, type ModpackIssue, validateKubejsData, validateModpackMeta,
} from '../modpack/validate';

/** `<dataDir>` 底下的整合包資料夾 */
export const MODPACKS_DIR = 'modpacks';

export interface LoadedModpack {
  readonly meta: CatalogModpack;
  readonly kubejs: KubejsData;
}

export type ModpackDataIssue = ModpackIssue & { readonly modpackId: string };

export interface ModpackLoadResult {
  readonly modpacks: readonly LoadedModpack[];
  readonly issues: readonly ModpackDataIssue[];
}

const ALLOWED_FILES: ReadonlySet<string> = new Set([KUBEJS_EN_FILE, KUBEJS_ZH_FILE]);

const isError = (i: ModpackIssue): boolean => i.level === 'error';

function isMissing(err: unknown): boolean {
  return (err as NodeJS.ErrnoException | undefined)?.code === 'ENOENT';
}

async function listEntries(dir: string): Promise<Dirent[] | null> {
  try {
    return await readdir(dir, { withFileTypes: true });
  } catch (err) {
    if (isMissing(err)) return null;
    throw err;
  }
}

type JsonRead = { readonly ok: true; readonly value: unknown } | { readonly ok: false; readonly issue: ModpackIssue };

/** optional 為 true 時檔案不存在回傳 null；否則回報「檔案不存在」 */
async function readJson(path: string, file: ModpackIssue['file'], optional: boolean): Promise<JsonRead | null> {
  let text: string;
  try {
    text = await readFile(path, 'utf8');
  } catch (err) {
    if (!isMissing(err)) throw err;
    return optional ? null : { ok: false, issue: { level: 'error', file, message: '檔案不存在' } };
  }
  try {
    return { ok: true, value: JSON.parse(stripBom(text)) as unknown };
  } catch (err) {
    const reason = err instanceof Error ? err.message : String(err);
    return { ok: false, issue: { level: 'error', file, message: `JSON 解析失敗：${reason}` } };
  }
}

interface NamespaceLoad {
  readonly texts?: KubejsTexts;
  readonly issues: readonly ModpackIssue[];
}

async function loadNamespace(root: string, ns: string, terms: readonly GlossaryTerm[]): Promise<NamespaceLoad> {
  if (!isValidNamespace(ns)) return { issues: validateKubejsData(ns, {}, {}) };
  const dir = join(root, ns);
  const extra = ((await listEntries(dir)) ?? [])
    .filter((e) => !e.isFile() || !ALLOWED_FILES.has(e.name))
    .map((e): ModpackIssue => ({ level: 'error', file: kubejsFile(ns, e.name), message: '只接受 en_us.json 與 zh_tw.json' }));
  const [en, zh] = await Promise.all([
    readJson(join(dir, KUBEJS_EN_FILE), kubejsFile(ns, KUBEJS_EN_FILE), false),
    readJson(join(dir, KUBEJS_ZH_FILE), kubejsFile(ns, KUBEJS_ZH_FILE), true),
  ]);
  const readIssues = [en, zh].flatMap((r) => (r && !r.ok ? [r.issue] : []));
  if (readIssues.length > 0 || !en?.ok) return { issues: [...extra, ...readIssues] };
  const zhValue = zh?.ok ? zh.value : {};
  const issues = [...extra, ...validateKubejsData(ns, en.value, zhValue, terms)];
  if (issues.some(isError)) return { issues };
  return { texts: { en: en.value as Record<string, string>, zh: zhValue as Record<string, string> }, issues };
}

async function loadKubejs(dir: string, terms: readonly GlossaryTerm[]): Promise<{ kubejs: KubejsData; issues: readonly ModpackIssue[] }> {
  const root = join(dir, KUBEJS_DIR);
  const entries = await listEntries(root);
  if (entries === null) return { kubejs: {}, issues: [] };
  const stray = entries
    .filter((e) => !e.isDirectory())
    .map((e): ModpackIssue => ({ level: 'error', file: `kubejs/${e.name}`, message: 'kubejs/ 底下只能放命名空間資料夾' }));
  const names = entries.filter((e) => e.isDirectory()).map((e) => e.name).sort();
  const loads = await Promise.all(names.map((ns) => loadNamespace(root, ns, terms)));
  const kubejs = Object.fromEntries(names.flatMap((ns, i) => {
    const texts = loads[i]?.texts;
    return texts ? [[ns, texts] as const] : [];
  }));
  return { kubejs, issues: [...stray, ...loads.flatMap((l) => l.issues)] };
}

async function loadOne(root: string, id: string, terms: readonly GlossaryTerm[]): Promise<{ modpack?: LoadedModpack; issues: ModpackDataIssue[] }> {
  const dir = join(root, id);
  const [meta, kubejs] = await Promise.all([readJson(join(dir, MODPACK_FILE), MODPACK_FILE, false), loadKubejs(dir, terms)]);
  const metaIssues = !meta ? [] : meta.ok ? validateModpackMeta(id, meta.value) : [meta.issue];
  const tagged = [...metaIssues, ...kubejs.issues].map((i) => ({ ...i, modpackId: id }));
  if (!meta?.ok || tagged.some(isError)) return { issues: tagged };
  return { modpack: { meta: catalogModpackSchema.parse(meta.value), kubejs: kubejs.kubejs }, issues: tagged };
}

/** 讀取 `<dataDir>/modpacks/*`；有 error 的整合包不會出現在 modpacks 中；terms 為全域術語 */
export async function loadAllModpacks(dataDir: string, terms: readonly GlossaryTerm[] = []): Promise<ModpackLoadResult> {
  const root = join(dataDir, MODPACKS_DIR);
  const entries = await listEntries(root);
  if (entries === null) return { modpacks: [], issues: [] };
  const names = entries.filter((e) => e.isDirectory()).map((e) => e.name).sort();
  const results = await Promise.all(names.map((id) => loadOne(root, id, terms)));
  return {
    modpacks: results.flatMap((r) => (r.modpack ? [r.modpack] : [])),
    issues: results.flatMap((r) => r.issues),
  };
}

/** 轉為 GitHub Actions 註記格式 */
export function formatModpackIssues(issues: readonly ModpackDataIssue[], dataDirLabel: string): string[] {
  return issues.map((i) => {
    const where = i.key ? `${i.key}：` : '';
    return `::${i.level} file=${dataDirLabel}/${MODPACKS_DIR}/${i.modpackId}/${i.file}::[modpack:${i.modpackId}] ${where}${i.message}`;
  });
}
```

```ts
const PREFIX = 'modpack';

/** 翻譯工具的專案 ID；與模組專案（id = modId）不會撞名 */
export function modpackProjectId(modpackId: string, ns: string): string {
  return `${PREFIX}:${modpackId}:${ns}`;
}

export function parseModpackProjectId(id: string): { readonly modpackId: string; readonly ns: string } | null {
  const parts = id.split(':');
  if (parts.length !== 3 || parts[0] !== PREFIX) return null;
  const [, modpackId = '', ns = ''] = parts;
  return isValidModpackId(modpackId) && isValidNamespace(ns) ? { modpackId, ns } : null;

  return `${name}（KubeJS：${ns}）`;

  return {
    modId: ns,
    name: kubejsProjectName(pack.name, ns),
    version: pack.version,
    jarName: '',
    format: 'json',
    source: texts.en,
    order: Object.keys(texts.en),
    zhTw: texts.zh,
  };
}

export function kubejsProject(pack: ModpackRef, ns: string, texts: KubejsTexts, now: number): ModProject {
  return { ...buildProject(toDetected(pack, ns, texts), now), id: modpackProjectId(pack.id, ns) };
}

  return mergeProject(existing, toDetected(pack, ns, texts), now);
}

export function kubejsProjects(pack: ModpackRef, kubejs: KubejsData, now: number): ModProject[] {
  return Object.keys(kubejs).sort().flatMap((ns) => {
    const texts = kubejs[ns];
    return texts ? [kubejsProject(pack, ns, texts, now)] : [];
  });

  if (projects.length === 0) return null;

    (acc, s) => ({ total: acc.total + s.total, translated: acc.translated + s.translated, warnings: acc.warnings + s.warnings }),
    { total: 0, translated: 0, warnings: 0 },
  );
  return { ...sums, percent: sums.total === 0 ? 0 : Math.round((sums.translated / sums.total) * 100) };
}
```

```ts
import type { ModProject, TranslationEntry } from '../types';

function combine(group: readonly ModProject[]): ModProject {
  const [first] = group;
  if (!first) throw new Error('empty namespace group');
  const byKey = new Map<string, TranslationEntry>();
  for (const p of group) {
    for (const e of p.entries) {
      if (e.status === 'obsolete' && byKey.has(e.key)) continue;
      byKey.set(e.key, e);
    }
  }
  const guide = group.find((p) => p.guide)?.guide;
  const { guide: _first, ...base } = first;
  return { ...base, entries: [...byKey.values()], ...(guide ? { guide } : {}) };
}

/**
 * 同一命名空間（modId）的專案合成一個，避免資源包中同路徑的語言檔互相覆蓋。
 * 條目依專案順序合併、同 key 以後者為準（後者的 obsolete 條目不覆蓋）；格式取第一個；手冊取第一個有手冊的專案。
 */
export function mergeSameNamespace(projects: readonly ModProject[]): ModProject[] {
  const groups = new Map<string, readonly ModProject[]>();
  for (const p of projects) groups.set(p.modId, [...(groups.get(p.modId) ?? []), p]);
  return [...groups.values()].map((group) => (group.length === 1 && group[0] ? group[0] : combine(group)));
}
```

```ts
import type { ZodType } from 'zod';

/** 新增整合包時的可預期錯誤；訊息直接給維護者看 */
export class ModpackImportError extends Error {
  constructor(message: string) {
    super(message);
    this.name = 'ModpackImportError';
  }
}

/** 以 zod 驗證外部資料，失敗時丟出可讀的 ModpackImportError */
export function parseOrThrow<T>(schema: ZodType<T>, raw: unknown, what: string): T {
  const result = schema.safeParse(raw);
  if (result.success) return result.data;
  const details = result.error.issues.map((i) => `${i.path.join('.') || '(root)'} ${i.message}`).join('；');
  throw new ModpackImportError(`${what} 格式不符：${details}`);
}
```

```ts
  const mc = index.dependencies.minecraft;
  if (!mc) throw new ModpackImportError('modrinth.index.json 缺少 dependencies.minecraft');
  const loader = MRPACK_LOADERS.find(([dep]) => Object.hasOwn(index.dependencies, dep))?.[1];
  if (!loader) throw new ModpackImportError(`modrinth.index.json ${NO_LOADER}`);
  const mods = index.files.filter((f) => f.path.startsWith('mods/'));
  const ids = mods.map((f) => f.downloads.map(modrinthProjectIdFromUrl).find((id) => id !== null) ?? null);
  return {
    mcVersion: knownMcVersion(mc),
    loader,
    projectIds: [...new Set(ids.filter((id): id is string => id !== null))],
    unknownFiles: mods.filter((_, i) => ids[i] === null).map((f) => f.path),
  };
}

const CURSE_LOADER = /^([a-z]+)-/;

export function parseCurseManifest(raw: unknown): ParsedCurseManifest {
  const manifest = parseOrThrow(curseSchema, raw, 'manifest.json');
  const { modLoaders } = manifest.minecraft;
  const primary = modLoaders.find((l) => l.primary === true) ?? modLoaders[0];
  const name = primary ? CURSE_LOADER.exec(primary.id)?.[1] : undefined;
  const loader = LOADERS.find((l) => l === name);
  if (!loader) throw new ModpackImportError(`manifest.json ${NO_LOADER}`);
  return {
    mcVersion: knownMcVersion(manifest.minecraft.version),
    loader,
    projectIds: [...new Set(manifest.files.map((f) => String(f.projectID)))],
    ...(manifest.version ? { version: manifest.version } : {}),
  };
```

```ts
import JSZip from 'jszip';
import { MAX_JAR_BYTES } from '../jar/errors';
import { LangParseError, parseJsonLang } from '../lang';
import { stripBom } from '../lang/types';
import { isValidNamespace } from '../modpack/schema';
import { ModpackImportError } from './errors';
import { parseCurseManifest, parseMrpackIndex, type ParsedCurseManifest, type ParsedMrpack } from './manifest';

/** 命名空間 → KubeJS 英文原文 */
export type KubejsEnglish = Readonly<Record<string, Readonly<Record<string, string>>>>;

export const MRPACK_INDEX = 'modrinth.index.json';
export const CURSE_MANIFEST = 'manifest.json';

/** 只讀 overrides/ 底下的 KubeJS 英文語言檔 */
const KUBEJS_LANG = /^overrides\/kubejs\/assets\/([^/]+)\/lang\/en_us\.json$/;

async function loadZip(bytes: Uint8Array, name: string): Promise<JSZip> {
  if (bytes.byteLength > MAX_JAR_BYTES) throw new ModpackImportError(`${name} 超過 ${MAX_JAR_BYTES} bytes`);
  try {
    return await JSZip.loadAsync(bytes);
  } catch {
    throw new ModpackImportError(`${name} 不是有效的壓縮檔`);
  }
}

async function readJson(zip: JSZip, path: string, name: string): Promise<unknown> {
  const file = zip.file(path);
  if (!file) throw new ModpackImportError(`${name} 裡沒有 ${path}`);
  const text = await file.async('string');
  try {
    return JSON.parse(stripBom(text)) as unknown;
  } catch (err) {
    throw new ModpackImportError(`${path} JSON 解析失敗：${err instanceof Error ? err.message : String(err)}`);
  }
}

async function readNamespace(zip: JSZip, ns: string, path: string): Promise<readonly [string, Readonly<Record<string, string>>]> {
  const text = (await zip.file(path)?.async('string')) ?? '';
  try {
    return [ns, parseJsonLang(text).entries];
  } catch (err) {
    if (err instanceof LangParseError) throw new ModpackImportError(`${path} 讀取失敗：${err.message}`);
    throw err;
  }
}

/** 命名空間不合法（含 . 與 ..）或沒有任何字串的檔案略過；非字串值略過 */
async function readKubejs(zip: JSZip): Promise<KubejsEnglish> {
  const found = Object.keys(zip.files)
    .flatMap((path) => {
      const ns = KUBEJS_LANG.exec(path)?.[1];
      return ns !== undefined && isValidNamespace(ns) ? [[ns, path] as const] : [];
    })
    .sort((a, b) => (a[0] < b[0] ? -1 : a[0] > b[0] ? 1 : 0));
  const entries = await Promise.all(found.map(([ns, path]) => readNamespace(zip, ns, path)));
  return Object.fromEntries(entries.filter(([, en]) => Object.keys(en).length > 0));
}

export async function readMrpack(bytes: Uint8Array, name: string): Promise<{ index: ParsedMrpack; kubejs: KubejsEnglish }> {
  const zip = await loadZip(bytes, name);
  const index = parseMrpackIndex(await readJson(zip, MRPACK_INDEX, name));
  return { index, kubejs: await readKubejs(zip) };
}

export async function readCurseZip(bytes: Uint8Array, name: string): Promise<{ manifest: ParsedCurseManifest; kubejs: KubejsEnglish }> {
  const zip = await loadZip(bytes, name);
  const manifest = parseCurseManifest(await readJson(zip, CURSE_MANIFEST, name));
  return { manifest, kubejs: await readKubejs(zip) };
}
```

```ts
  type CatalogModpack, catalogModpackSchema, isValidModpackId, type ModpackLoader, type ModpackMod, type ModpackPlatform,

import { findKeyConflicts, type KeyConflict } from '../pipeline/addSourceVersion';

import type { KubejsEnglish } from './archive';

export const AUTHOR_PLACEHOLDER = '（待補作者）';

/** 從平台與壓縮檔取得的整合包資料 */
export interface ImportedModpack {
  readonly platform: ModpackPlatform;
  readonly projectId: string;
  readonly slug: string;
  readonly name: string;
  readonly authors: readonly string[];
  readonly version: string;
  readonly mcVersion: string;
  readonly loader: ModpackLoader;
  readonly mods: readonly ModpackMod[];
  readonly kubejs: KubejsEnglish;
  /** 給維護者看的提示（略過的檔案、查不到的專案） */
  readonly notes: readonly string[];
}

export interface ExistingModpack {
  readonly meta: CatalogModpack;
  readonly kubejsEn: KubejsEnglish;
}

export interface NamespaceChange {
  readonly ns: string;
  readonly created: boolean;
  readonly addedKeys: readonly string[];
  /** 原文不同的 key（保留既有原文） */
  readonly conflicts: readonly KeyConflict[];
}

export interface NamespacedConflict extends KeyConflict {
  readonly ns: string;
}

export type ModpackPlan =
  | { readonly kind: 'write'; readonly meta: CatalogModpack; readonly kubejsEn: KubejsEnglish; readonly changes: readonly NamespaceChange[] }
  | { readonly kind: 'refused'; readonly conflicts: readonly NamespacedConflict[] };

/** 平台 slug → 整合包 id（小寫）；不符合 id 規則時為 null */
export function modpackIdFromSlug(slug: string): string | null {
  const id = slug.toLowerCase();
  return isValidModpackId(id) ? id : null;
}

function sourceOf(incoming: ImportedModpack): CatalogModpack['source'] {
  const { platform, projectId, version, mcVersion, loader } = incoming;
  return { platform, projectId, version, mcVersion, loader };
}

function linkOf(incoming: ImportedModpack): Partial<CatalogModpack['links']> {
  return { [incoming.platform]: platformModpackUrl(incoming.platform, incoming.slug) };
}

function draftMeta(id: string, incoming: ImportedModpack, today: string): CatalogModpack {
  return catalogModpackSchema.parse({
    id,
    name: incoming.name,
    summary: SUMMARY_PLACEHOLDER,
    authors: incoming.authors.length > 0 ? incoming.authors : [AUTHOR_PLACEHOLDER],
    links: linkOf(incoming),
    source: sourceOf(incoming),
    mods: incoming.mods,
    translation: { status: 'machine', license: 'CC-BY-SA-4.0', source: { name: MACHINE_SOURCE_NAME, url: null }, contributors: [] },
    updatedAt: today,
  });
}

/** 更新只動 source、mods、平台連結與日期；名稱、簡介、作者、翻譯資訊由維護者維護 */
function updatedMeta(meta: CatalogModpack, incoming: ImportedModpack, today: string): CatalogModpack {
  return catalogModpackSchema.parse({
    ...meta,
    links: { ...meta.links, ...linkOf(incoming) },
    source: sourceOf(incoming),
    mods: incoming.mods,
    updatedAt: today,
  });
}

interface NamespaceResult {
  readonly change: NamespaceChange;
  readonly en: Readonly<Record<string, string>>;
}

/** 沿用 addSourceVersion：既有原文優先，新 key 依序附加在最後 */
function mergeNamespace(ns: string, current: Readonly<Record<string, string>> | undefined, incoming: Readonly<Record<string, string>>): NamespaceResult {
  const base = current ?? {};
  const addedKeys = Object.keys(incoming).filter((k) => !Object.hasOwn(base, k));
  return {
    change: { ns, created: current === undefined, addedKeys, conflicts: findKeyConflicts(base, incoming) },
    en: { ...base, ...Object.fromEntries(addedKeys.map((k) => [k, incoming[k] ?? ''])) },
  };
}

/** 決定要寫入的 modpack.json 與 KubeJS 英文；任何格式碼衝突都拒絕寫入 */
export function planModpackWrite(id: string, existing: ExistingModpack | null, incoming: ImportedModpack, today: string): ModpackPlan {
  const results = Object.keys(incoming.kubejs).sort().map((ns) => mergeNamespace(ns, existing?.kubejsEn[ns], incoming.kubejs[ns] ?? {}));
  const refused = results.flatMap(({ change }) =>
    change.conflicts.filter((c) => c.formatChanged).map((c): NamespacedConflict => ({ ...c, ns: change.ns })));
  if (refused.length > 0) return { kind: 'refused', conflicts: refused };
  const written = results.filter(({ change }) => change.created || change.addedKeys.length > 0);
  return {
    kind: 'write',
    meta: existing ? updatedMeta(existing.meta, incoming, today) : draftMeta(id, incoming, today),
    kubejsEn: Object.fromEntries(written.map(({ change, en }) => [change.ns, en])),
    changes: results.map((r) => r.change),
  };
}
```

```ts
export interface FetchCall {
  readonly url: string;
  readonly init?: FetchInit;
}

export type FakeFetch = FetchLike & { readonly calls: readonly FetchCall[] };

function respond(body: unknown): FetchResponse {
  return {
    ok: true,
    status: 200,
    json: async () => body,
    arrayBuffer: async () => {
      if (!(body instanceof Uint8Array)) throw new Error('route is not a file');
      return body.buffer.slice(body.byteOffset, body.byteOffset + body.byteLength) as ArrayBuffer;
    },
  };
}

const NOT_FOUND: FetchResponse = { ok: false, status: 404, json: async () => ({}), arrayBuffer: async () => new ArrayBuffer(0) };

export function fakeFetch(routes: Readonly<Record<string, unknown>>): FakeFetch {
  const calls: FetchCall[] = [];
  const fetchImpl = async (url: string, init?: FetchInit): Promise<FetchResponse> => {
    calls.push(init ? { url, init } : { url });
```

```ts
import { MAX_JAR_BYTES } from '../jar/errors';
import { ModpackImportError } from './errors';

export const USER_AGENT = 'ModLangForge/0.1 (+https://github.com/MrPippi/ModLangForge)';

export interface FetchInit {
  readonly method?: 'GET' | 'POST';
  readonly headers?: Readonly<Record<string, string>>;
  readonly body?: string;
}

export interface FetchResponse {
  readonly ok: boolean;
  readonly status: number;
  json(): Promise<unknown>;
  arrayBuffer(): Promise<ArrayBuffer>;
}

/** 腳本傳入全域 fetch；測試注入假 fetch */
export type FetchLike = (url: string, init?: FetchInit) => Promise<FetchResponse>;

/** 錯誤訊息只含狀態碼與網址，不含標頭（避免帶出金鑰） */
export async function fetchJson(fetchImpl: FetchLike, url: string, init: FetchInit = {}): Promise<unknown> {
  const res = await fetchImpl(url, { ...init, headers: { 'User-Agent': USER_AGENT, ...init.headers } });
  if (!res.ok) throw new ModpackImportError(`HTTP ${res.status} ${url}`);
  return res.json();
}

/** 下載檔案；只帶 User-Agent，不帶任何 API 金鑰 */
export async function fetchBytes(fetchImpl: FetchLike, url: string, maxBytes: number = MAX_JAR_BYTES): Promise<Uint8Array> {
  const res = await fetchImpl(url, { headers: { 'User-Agent': USER_AGENT } });
  if (!res.ok) throw new ModpackImportError(`HTTP ${res.status} ${url}`);
  const bytes = new Uint8Array(await res.arrayBuffer());
  if (bytes.byteLength > maxBytes) throw new ModpackImportError(`${url} 超過 ${maxBytes} bytes`);
  return bytes;
}

export function chunk<T>(list: readonly T[], size: number): T[][] {
  return Array.from({ length: Math.ceil(list.length / size) }, (_, i) => list.slice(i * size, (i + 1) * size));
}
```

```ts
import { z } from 'zod';
import type { ModpackMod } from '../modpack/schema';
import { readMrpack } from './archive';
import { ModpackImportError, parseOrThrow } from './errors';
import { chunk, type FetchLike, fetchBytes, fetchJson } from './http';
import type { ImportedModpack } from './plan';

export const MODRINTH_API = 'https://api.modrinth.com/v2';
const BATCH_SIZE = 100;

const projectSchema = z.object({ id: z.string().min(1), slug: z.string().min(1), title: z.string().min(1), project_type: z.string() });
const membersSchema = z.array(z.object({ user: z.object({ username: z.string().min(1) }) }));
const versionsSchema = z.array(z.object({
  version_number: z.string().min(1),
  date_published: z.string(),
  files: z.array(z.object({ url: z.string(), filename: z.string(), primary: z.boolean() })),
}));
const projectsSchema = z.array(z.object({ id: z.string().min(1), slug: z.string().min(1) }));

type MrVersion = z.infer<typeof versionsSchema>[number];

export interface ModrinthImportArgs {
  /** slug 或專案 ID */
  readonly ref: string;
  /** version_number；省略時取最新發佈 */
  readonly version?: string;
}

function pickVersion(versions: readonly MrVersion[], wanted: string | undefined): MrVersion {
  if (wanted !== undefined) {
    const found = versions.find((v) => v.version_number === wanted);
    if (!found) throw new ModpackImportError(`Modrinth 上找不到版本 ${wanted}`);
    return found;
  }
  const latest = [...versions].sort((a, b) => b.date_published.localeCompare(a.date_published))[0];
  if (!latest) throw new ModpackImportError('Modrinth 上沒有任何版本');
  return latest;
}

function mrpackFile(version: MrVersion): MrVersion['files'][number] {
  const packs = version.files.filter((f) => f.filename.endsWith('.mrpack'));
  const file = packs.find((f) => f.primary) ?? packs[0];
  if (!file) throw new ModpackImportError(`${version.version_number} 沒有 .mrpack 檔案`);
  return file;
}

async function lookupSlugs(fetchImpl: FetchLike, ids: readonly string[]): Promise<ReadonlyMap<string, string>> {
  const batches = await Promise.all(chunk(ids, BATCH_SIZE).map(async (batch) => {
    const url = `${MODRINTH_API}/projects?ids=${encodeURIComponent(JSON.stringify(batch))}`;
    return parseOrThrow(projectsSchema, await fetchJson(fetchImpl, url), 'Modrinth 專案清單');
  }));
  return new Map(batches.flat().map((p) => [p.id, p.slug]));
}

export async function importFromModrinth(fetchImpl: FetchLike, args: ModrinthImportArgs): Promise<ImportedModpack> {
  const projectUrl = `${MODRINTH_API}/project/${encodeURIComponent(args.ref)}`;
  const project = parseOrThrow(projectSchema, await fetchJson(fetchImpl, projectUrl), 'Modrinth 專案');
  if (project.project_type !== 'modpack') throw new ModpackImportError(`${project.slug} 不是整合包（類型：${project.project_type}）`);
  const [members, versions] = await Promise.all([
    fetchJson(fetchImpl, `${MODRINTH_API}/project/${project.id}/members`).then((raw) => parseOrThrow(membersSchema, raw, 'Modrinth 成員')),
    fetchJson(fetchImpl, `${MODRINTH_API}/project/${project.id}/version`).then((raw) => parseOrThrow(versionsSchema, raw, 'Modrinth 版本')),
  ]);
  const version = pickVersion(versions, args.version);
  const file = mrpackFile(version);
  const { index, kubejs } = await readMrpack(await fetchBytes(fetchImpl, file.url), file.filename);
  const slugs = await lookupSlugs(fetchImpl, index.projectIds);
  const mods: ModpackMod[] = index.projectIds.flatMap((id) => {
    const slug = slugs.get(id);
    return slug ? [{ platform: 'modrinth' as const, projectId: id, slug }] : [];
  });
  const notes = [
    ...index.unknownFiles.map((path) => `略過非 Modrinth 來源的檔案：${path}`),
    ...index.projectIds.filter((id) => !slugs.has(id)).map((id) => `Modrinth 查不到專案 ${id}，未列入模組清單`),
  ];
  return {
    platform: 'modrinth',
    projectId: project.id,
    slug: project.slug,
    name: project.title,
    authors: [...new Set(members.map((m) => m.user.username))],
    version: version.version_number,
    mcVersion: index.mcVersion,
    loader: index.loader,
    mods,
    kubejs,
    notes,
  };
}
```

```ts
import { z } from 'zod';
import type { ModpackMod } from '../modpack/schema';
import { readCurseZip } from './archive';
import { ModpackImportError, parseOrThrow } from './errors';
import { chunk, type FetchLike, fetchBytes, fetchJson } from './http';
import type { ImportedModpack } from './plan';

export const CURSEFORGE_API = 'https://api.curseforge.com/v1';
export const CURSEFORGE_GAME_ID = 432;
export const CURSEFORGE_MODPACK_CLASS = 4471;
export const CURSEFORGE_MOD_CLASS = 6;
const BATCH_SIZE = 100;

const modSchema = z.object({
  id: z.number().int(),
  name: z.string().min(1),
  slug: z.string().min(1),
  classId: z.number().int().nullish(),
  authors: z.array(z.object({ name: z.string().min(1) })),
});
const oneModSchema = z.object({ data: modSchema });
const searchSchema = z.object({ data: z.array(modSchema) });
const filesSchema = z.object({
  data: z.array(z.object({
    id: z.number().int(),
    displayName: z.string(),
    fileName: z.string(),
    fileDate: z.string(),
    downloadUrl: z.string().nullable(),
    isServerPack: z.boolean().nullish(),
  })),
});
const lookupSchema = z.object({ data: z.array(z.object({ id: z.number().int(), slug: z.string().min(1), classId: z.number().int().nullish() })) });

type CfMod = z.infer<typeof modSchema>;
type CfFile = z.infer<typeof filesSchema>['data'][number];
type CfLookup = z.infer<typeof lookupSchema>['data'][number];

/** 維護者以 --file 提供的整合包 zip */
export interface LocalFile {
  readonly name: string;
  readonly bytes: Uint8Array;
}

export interface CurseforgeImportArgs {
  /** slug 或數字專案 ID */
  readonly ref: string;
  readonly apiKey: string;
  /** 檔案的 displayName、fileName 或 id；省略時取最新的非伺服器檔 */
  readonly version?: string;
  readonly localFile?: LocalFile;
}

/** 金鑰只放在送往 CURSEFORGE_API 的請求；下載 CDN 不帶金鑰 */
function apiHeaders(apiKey: string): Readonly<Record<string, string>> {
  return { 'x-api-key': apiKey, Accept: 'application/json' };
}

export function noDownloadMessage(file: string): string {
  return `${file} 不允許第三方下載。請從 CurseForge 網站手動下載整合包 zip，再加上 --file <路徑> 重新執行。`;
}

async function findModpack(fetchImpl: FetchLike, ref: string, apiKey: string): Promise<CfMod> {
  const headers = apiHeaders(apiKey);
  const mod = /^\d+$/.test(ref)
    ? parseOrThrow(oneModSchema, await fetchJson(fetchImpl, `${CURSEFORGE_API}/mods/${ref}`, { headers }), 'CurseForge 專案').data
    : parseOrThrow(
      searchSchema,
      await fetchJson(fetchImpl, `${CURSEFORGE_API}/mods/search?gameId=${CURSEFORGE_GAME_ID}&classId=${CURSEFORGE_MODPACK_CLASS}&slug=${encodeURIComponent(ref)}`, { headers }),
      'CurseForge 搜尋結果',
    ).data[0];
  if (!mod) throw new ModpackImportError(`CurseForge 上找不到整合包 ${ref}`);
  if (mod.classId !== CURSEFORGE_MODPACK_CLASS) throw new ModpackImportError(`${mod.slug} 不是整合包`);
  return mod;
}

function pickFile(files: readonly CfFile[], wanted: string | undefined): CfFile {
  const clientFiles = files.filter((f) => f.isServerPack !== true);
  if (wanted !== undefined) {
    const found = clientFiles.find((f) => f.displayName === wanted || f.fileName === wanted || String(f.id) === wanted);
    if (!found) throw new ModpackImportError(`CurseForge 上找不到檔案 ${wanted}`);
    return found;
  }
  const latest = [...clientFiles].sort((a, b) => b.fileDate.localeCompare(a.fileDate))[0];
  if (!latest) throw new ModpackImportError('CurseForge 上沒有可用的整合包檔案');
  return latest;
}

interface PackFile {
  readonly name: string;
  readonly bytes: Uint8Array;
  readonly displayName?: string;
}

async function packFile(fetchImpl: FetchLike, modId: number, args: CurseforgeImportArgs): Promise<PackFile> {
  if (args.localFile) return { name: args.localFile.name, bytes: args.localFile.bytes };
  const url = `${CURSEFORGE_API}/mods/${modId}/files?pageSize=50`;
  const files = parseOrThrow(filesSchema, await fetchJson(fetchImpl, url, { headers: apiHeaders(args.apiKey) }), 'CurseForge 檔案清單').data;
  const file = pickFile(files, args.version);
  if (!file.downloadUrl) throw new ModpackImportError(noDownloadMessage(file.displayName));
  return { name: file.fileName, bytes: await fetchBytes(fetchImpl, file.downloadUrl), displayName: file.displayName };
}

async function lookupMods(fetchImpl: FetchLike, ids: readonly string[], apiKey: string): Promise<ReadonlyMap<string, CfLookup>> {
  const headers = { ...apiHeaders(apiKey), 'Content-Type': 'application/json' };
  const batches = await Promise.all(chunk(ids, BATCH_SIZE).map(async (batch) => {
    const body = JSON.stringify({ modIds: batch.map(Number) });
    const raw = await fetchJson(fetchImpl, `${CURSEFORGE_API}/mods`, { method: 'POST', headers, body });
    return parseOrThrow(lookupSchema, raw, 'CurseForge 模組清單').data;
  }));
  return new Map(batches.flat().map((m) => [String(m.id), m]));
}

/** 只有 classId 6（模組）列入 mods；資源包等其他專案與查不到的專案寫入 notes */
function describeMods(ids: readonly string[], found: ReadonlyMap<string, CfLookup>): { mods: ModpackMod[]; notes: string[] } {
  const mods = ids.flatMap((id) => {
    const m = found.get(id);
    return m && m.classId === CURSEFORGE_MOD_CLASS ? [{ platform: 'curseforge' as const, projectId: id, slug: m.slug }] : [];
  });
  const notes = ids.flatMap((id) => {
    const m = found.get(id);
    if (!m) return [`CurseForge 查不到專案 ${id}，未列入模組清單`];
    return m.classId === CURSEFORGE_MOD_CLASS ? [] : [`略過非模組專案 ${m.slug}`];
  });
  return { mods, notes };
}

export async function importFromCurseforge(fetchImpl: FetchLike, args: CurseforgeImportArgs): Promise<ImportedModpack> {
  const pack = await findModpack(fetchImpl, args.ref, args.apiKey);
  const file = await packFile(fetchImpl, pack.id, args);
  const { manifest, kubejs } = await readCurseZip(file.bytes, file.name);
  const { mods, notes } = describeMods(manifest.projectIds, await lookupMods(fetchImpl, manifest.projectIds, args.apiKey));
  return {
    platform: 'curseforge',
    projectId: String(pack.id),
    slug: pack.slug,
    name: pack.name,
    authors: [...new Set(pack.authors.map((a) => a.name))],
    version: manifest.version ?? file.displayName ?? file.name,
    mcVersion: manifest.mcVersion,
    loader: manifest.loader,
    mods,
    kubejs,
    notes,
  };
}
```

```ts
import type { CatalogModpack, ModpackPlatform } from '../modpack/schema';
import type { KubejsEnglish } from './archive';
import { importFromCurseforge, type LocalFile } from './curseforge';
import type { FetchLike } from './http';
import { importFromModrinth } from './modrinth';
import { type ExistingModpack, type ImportedModpack, modpackIdFromSlug, type NamespaceChange, type NamespacedConflict, planModpackWrite } from './plan';

export const CURSEFORGE_KEY_ENV = 'CURSEFORGE_API_KEY';

export const MISSING_KEY_MESSAGE = [
  `未設定 ${CURSEFORGE_KEY_ENV}，無法使用 CurseForge API。`,
  '1. 到 https://console.curseforge.com/ 申請 API 金鑰。',
  `2. 在專案根目錄的 .env 加入一行 ${CURSEFORGE_KEY_ENV}=<你的金鑰>（.env 不會被提交），或設定同名環境變數後重新執行。`,
].join('\n');

const REDACTED = '[已隱藏]';

export interface AddModpackArgs {
  readonly platform: ModpackPlatform;
  /** slug 或專案 ID */
  readonly ref: string;
  readonly version?: string;
  /** 只用於 CurseForge：手動下載的整合包 zip */
  readonly filePath?: string;
}

/** 寫入 data/modpacks/<id>/ 的內容；不含 zh_tw.json */
export interface ModpackFiles {
  readonly meta: CatalogModpack;
  /** 只含需要寫入的命名空間 */
  readonly kubejsEn: KubejsEnglish;
}

/** 腳本提供真實實作，測試注入假實作 */
export interface AddModpackIO {
  readonly fetch: FetchLike;
  /** CURSEFORGE_API_KEY；只在記憶體中使用，不寫入、不印出 */
  readonly apiKey: string | undefined;
  readonly readLocalFile: (path: string) => Promise<Uint8Array>;
  readonly readExisting: (id: string) => Promise<ExistingModpack | null>;
  readonly write: (id: string, files: ModpackFiles) => Promise<void>;
}

export type AddModpackResult =
  | { readonly kind: 'written'; readonly id: string; readonly created: boolean; readonly changes: readonly NamespaceChange[]; readonly notes: readonly string[] }
  | { readonly kind: 'conflict'; readonly id: string; readonly conflicts: readonly NamespacedConflict[] }
  | { readonly kind: 'error'; readonly message: string };

function redact(message: string, secret: string | undefined): string {
  return secret ? message.split(secret).join(REDACTED) : message;
}

function fileName(path: string): string {
  return path.split(/[\\/]/).pop() || path;
}

async function importPack(io: AddModpackIO, args: AddModpackArgs, apiKey: string): Promise<ImportedModpack> {
  if (args.platform === 'modrinth') return importFromModrinth(io.fetch, { ref: args.ref, version: args.version });
  const localFile: LocalFile | undefined = args.filePath === undefined
    ? undefined
    : { name: fileName(args.filePath), bytes: await io.readLocalFile(args.filePath) };
  return importFromCurseforge(io.fetch, { ref: args.ref, apiKey, version: args.version, localFile });
}

/** 新增或更新一個整合包；格式碼衝突時不寫入任何檔案 */
export async function runAddModpack(io: AddModpackIO, args: AddModpackArgs, today: string): Promise<AddModpackResult> {
  if (args.platform === 'modrinth' && args.filePath !== undefined) return { kind: 'error', message: '--file 只能搭配 --curseforge 使用' };
  const apiKey = io.apiKey ?? '';
  if (args.platform === 'curseforge' && apiKey === '') return { kind: 'error', message: MISSING_KEY_MESSAGE };
  try {
    const incoming = await importPack(io, args, apiKey);
    const id = modpackIdFromSlug(incoming.slug);
    if (!id) return { kind: 'error', message: `整合包 slug「${incoming.slug}」不能當作 id（只能包含 a-z 0-9 _ . -）` };
    const existing = await io.readExisting(id);
    const plan = planModpackWrite(id, existing, incoming, today);
    if (plan.kind === 'refused') return { kind: 'conflict', id, conflicts: plan.conflicts };
    await io.write(id, { meta: plan.meta, kubejsEn: plan.kubejsEn });
    return { kind: 'written', id, created: existing === null, changes: plan.changes, notes: incoming.notes };
  } catch (err) {
    return { kind: 'error', message: redact(err instanceof Error ? err.message : String(err), io.apiKey) };
  }
}
```

```ts
import type { ExistingModpack, ModpackFiles } from '@mlf/core/modpackImport';
import { writeFilesTogether } from '@mlf/core/node';
import { toJson } from './modrinth';

export const MODPACKS_DIR = resolve(import.meta.dirname, '..', '..', 'data', 'modpacks');

function isMissing(err: unknown): boolean {
  return (err as NodeJS.ErrnoException | undefined)?.code === 'ENOENT';
}

async function readJsonOrNull(path: string): Promise<unknown> {
  try {
    return JSON.parse(await readFile(path, 'utf8')) as unknown;
  } catch (err) {
    if (isMissing(err)) return null;
    throw err;
  }
}

async function readKubejsEnglish(dir: string): Promise<ExistingModpack['kubejsEn']> {
  const root = join(dir, KUBEJS_DIR);
  let names: string[];
  try {
    names = (await readdir(root, { withFileTypes: true })).filter((e) => e.isDirectory()).map((e) => e.name);
  } catch (err) {
    if (isMissing(err)) return {};
    throw err;
  }
  const entries = await Promise.all(names.map(async (ns) => [ns, await readJsonOrNull(join(root, ns, KUBEJS_EN_FILE))] as const));
  return Object.fromEntries(entries.filter(([, en]) => en !== null).map(([ns, en]) => [ns, langRecordSchema.parse(en)]));
}

/** 讀取既有的 data/modpacks/<id>；不存在時回傳 null */
export async function readExisting(id: string): Promise<ExistingModpack | null> {
  const dir = join(MODPACKS_DIR, id);
  const raw = await readJsonOrNull(join(dir, MODPACK_FILE));
  if (raw === null) return null;
  return { meta: catalogModpackSchema.parse(raw), kubejsEn: await readKubejsEnglish(dir) };
}

/** 寫入 modpack.json 與有變動的 kubejs/<ns>/en_us.json；不動 zh_tw.json。id 與命名空間已在 core 驗證 */
export async function writeModpack(id: string, { meta, kubejsEn }: ModpackFiles): Promise<void> {
  const dir = join(MODPACKS_DIR, id);
  const namespaces = Object.keys(kubejsEn);
  await Promise.all([dir, ...namespaces.map((ns) => join(dir, KUBEJS_DIR, ns))].map((d) => mkdir(d, { recursive: true })));
  await writeFilesTogether([
    { path: join(dir, MODPACK_FILE), content: toJson(meta) },
    ...namespaces.map((ns) => ({ path: join(dir, KUBEJS_DIR, ns, KUBEJS_EN_FILE), content: toJson(kubejsEn[ns]) })),
  ]);
}
```

```ts
/**
 * 新增或更新整合包：下載 .mrpack／CurseForge zip，寫入 data/modpacks/<id>/modpack.json 與 KubeJS 英文原文（不動 zh_tw.json）。

 * CurseForge 需要 CURSEFORGE_API_KEY（環境變數或專案根目錄 .env）；金鑰不會寫入檔案，也不會印出。
 */
import { existsSync } from 'node:fs';
import { readFile } from 'node:fs/promises';
import { resolve } from 'node:path';
import { parseArgs } from 'node:util';
import { type AddModpackArgs, type AddModpackResult, CURSEFORGE_KEY_ENV, runAddModpack } from '@mlf/core/modpackImport';
import { readExisting, writeModpack } from './lib/modpackFiles';

const USAGE = '用法：npm run add:modpack -- --modrinth <slug|id> 或 --curseforge <slug|id>（可加 --version <版本>、--file <zip 路徑>）';
const ENV_FILE = resolve(import.meta.dirname, '..', '.env');

function parseCli(): AddModpackArgs {
  const { values } = parseArgs({
    options: { modrinth: { type: 'string' }, curseforge: { type: 'string' }, version: { type: 'string' }, file: { type: 'string' } },
  });
  const { modrinth, curseforge, version, file } = values;
  if ((modrinth === undefined) === (curseforge === undefined)) throw new Error(USAGE);
  const base = modrinth !== undefined
    ? { platform: 'modrinth' as const, ref: modrinth }
    : { platform: 'curseforge' as const, ref: curseforge ?? '' };
  return { ...base, ...(version !== undefined ? { version } : {}), ...(file !== undefined ? { filePath: file } : {}) };
}

function report(result: AddModpackResult): void {
  switch (result.kind) {
    case 'error':
      console.error(result.message);
      process.exitCode = 1;
      return;
    case 'conflict':
      for (const c of result.conflicts) console.log(`格式碼衝突  ${c.ns}:${c.key}\n  既有：${c.existing}\n  新版：${c.incoming}`);
      console.error('有格式碼衝突，未寫入任何檔案；請人工決定是否改寫原文。');
      process.exitCode = 1;
      return;
    case 'written':
      for (const note of result.notes) console.log(note);
      for (const change of result.changes) {
        for (const c of change.conflicts) console.log(`原文不同  ${change.ns}:${c.key}\n  既有：${c.existing}\n  新版：${c.incoming}`);
        console.log(`KubeJS ${change.ns}：${change.created ? '新增' : '更新'}，新增 ${change.addedKeys.length} 個 key`);
      }
      console.log(`${result.created ? '已新增' : '已更新'} data/modpacks/${result.id}（請確認名稱、簡介與作者）`);
  }
}

async function main(): Promise<void> {
  const args = parseCli();
  if (existsSync(ENV_FILE)) process.loadEnvFile(ENV_FILE);
  const result = await runAddModpack({
    fetch,
    apiKey: process.env[CURSEFORGE_KEY_ENV]?.trim() || undefined,
    readLocalFile: async (path) => new Uint8Array(await readFile(path)),
    readExisting,
    write: writeModpack,
  }, args, new Date().toLocaleDateString('sv-SE'));
  report(result);
}

main().catch((err: unknown) => {
  console.error('add-modpack 執行失敗：', err instanceof Error ? err.message : err);
  process.exitCode = 1;
});
```

```ts
import type { ProjectStats } from '@mlf/core/merge';
import {
  type CatalogModpack, includedModIds, kubejsProjects, kubejsStats, type ModpackMod, modpackRef, resolveModpackMods, type ResolvedModpackMod,
} from '@mlf/core/modpack';
import type { LoadedModpack } from '@mlf/core/node';
import type { SiteMod } from './data';
import type { IncludedMod, ModpackSummary } from './modpackSummary';

export interface SiteModpack extends LoadedModpack {
  /** 整合包的每個模組＋對照到的 modId */
  readonly resolved: readonly ResolvedModpackMod[];
  readonly included: readonly IncludedMod[];
  readonly missing: readonly ModpackMod[];
  /** KubeJS 進度（各命名空間合計）；沒有 KubeJS 文字時為 null */
  readonly kubejsStats: ProjectStats | null;
}

/** 建置時以 slug 對照已收錄模組並計算 KubeJS 進度 */
export function toSiteModpack(pack: LoadedModpack, catalog: readonly Pick<SiteMod, 'meta' | 'stats'>[]): SiteModpack {
  const resolved = resolveModpackMods(pack.meta.mods, catalog.map((m) => ({ modId: m.meta.modId, links: m.meta.links })));
  const byId = new Map(catalog.map((m) => [m.meta.modId, m]));
  const included = includedModIds(resolved).flatMap((modId): IncludedMod[] => {
    const mod = byId.get(modId);
    return mod ? [{ modId, name: mod.meta.name, nameZh: mod.meta.nameZh ?? null, percent: mod.stats.percent }] : [];
  });
  const missing = resolved.filter((m) => m.modId === null).map(({ modId: _modId, ...rest }): ModpackMod => rest);
  const stats = kubejsStats(kubejsProjects(modpackRef(pack.meta), pack.kubejs, 0));
  return { ...pack, resolved, included, missing, kubejsStats: stats };
}

export function toModpackSummary(p: SiteModpack): ModpackSummary {
  const { meta, kubejsStats: stats } = p;
  return {
    id: meta.id,
    name: meta.name,
    nameZh: meta.nameZh ?? null,
    summary: meta.summary,
    mcVersion: meta.source.mcVersion,
    loader: meta.source.loader,
    status: meta.translation.status,
    includedMods: p.resolved.filter((m) => m.modId !== null).length,
    totalMods: meta.mods.length,
    kubejs: stats ? { total: stats.total, translated: stats.translated, percent: stats.percent } : null,
    updatedAt: meta.updatedAt,
  };
}

export function byModpackName(a: ModpackSummary, b: ModpackSummary): number {
  return a.name.localeCompare(b.name);
}

/** /api/v1/modpacks/<id>.json 的內容 */
export interface ModpackApiBody {
  readonly version: 1;
  readonly meta: CatalogModpack;
  readonly mods: readonly ResolvedModpackMod[];
  readonly kubejs: Readonly<Record<string, { readonly en_us: Readonly<Record<string, string>>; readonly zh_tw: Readonly<Record<string, string>> }>>;
}

export function toModpackApiBody(p: Pick<SiteModpack, 'meta' | 'resolved' | 'kubejs'>): ModpackApiBody {
  return {
    version: 1,
    meta: p.meta,
    mods: p.resolved,
    kubejs: Object.fromEntries(Object.entries(p.kubejs).map(([ns, texts]) => [ns, { en_us: texts.en, zh_tw: texts.zh }])),
  };
}
```

```ts
import { z } from 'zod';
import { exportProjects, type ExportResult } from '@mlf/core/export';
import {
  type CatalogModpack, catalogModpackSchema, includedModIds, isValidNamespace, type KubejsData, kubejsProjects, langRecordSchema, modpackRef,
  resolvedModpackModSchema, type ResolvedModpackMod,
} from '@mlf/core/modpack';
import { modpackApiUrl } from '../lib/config';
import { fetchModData, type ModPayload, payloadToProject } from './downloadPack';

type FetchLike = NonNullable<Parameters<typeof fetchModData>[1]>;

export interface ModpackPayload {
  readonly meta: CatalogModpack;
  readonly mods: readonly ResolvedModpackMod[];
  readonly kubejs: KubejsData;
}

/** 命名空間會成為資源包路徑 assets/<ns>/lang/，不合法者整份 payload 視為無效 */
const namespace = z.string().refine(isValidNamespace, { message: '命名空間不合法' });

const payloadSchema = z.object({
  version: z.literal(1),
  meta: catalogModpackSchema,
  mods: z.array(resolvedModpackModSchema),
  kubejs: z.record(namespace, z.object({ en_us: langRecordSchema, zh_tw: langRecordSchema })),
});

export async function fetchModpackData(id: string, fetchImpl: FetchLike = fetch): Promise<ModpackPayload> {
  const res = await fetchImpl(modpackApiUrl(id));
  if (!res.ok) throw new Error(`HTTP ${res.status} for modpack ${id}`);
  const body = payloadSchema.parse(await res.json());
  return {
    meta: body.meta,
    mods: body.mods,
    kubejs: Object.fromEntries(Object.entries(body.kubejs).map(([ns, texts]) => [ns, { en: texts.en_us, zh: texts.zh_tw }])),
  };
}

/** 取得整合包中已收錄的模組；每個 modId 只請求一次，已下架（404）的模組略過 */
export async function fetchIncludedMods(pack: ModpackPayload, fetchImpl: FetchLike = fetch): Promise<ModPayload[]> {
  const payloads = await Promise.all(includedModIds(pack.mods).map((id) => fetchModData(id, fetchImpl)));
  return payloads.filter((p): p is ModPayload => p !== null);
}

export function modpackPackFileName(id: string, mcVersion: string): string {
  return `${id}-zh_tw-${mcVersion}.zip`;
}

/** 已收錄模組（含手冊）＋ KubeJS 譯文合成一個資源包；pack_format 依整合包的 Minecraft 版本，未翻譯的條目保留英文 */
export async function buildModpackPack(pack: ModpackPayload, mods: readonly ModPayload[]): Promise<ExportResult> {
  const projects = [...mods.map(payloadToProject), ...kubejsProjects(modpackRef(pack.meta), pack.kubejs, 0)];
  const { mcVersion } = pack.meta.source;
  const result = await exportProjects(projects, {
    kind: 'merged-pack',
    untranslated: 'keep-source',
    mcVersion,
    description: `ModLangForge 繁中翻譯 · ${pack.meta.name} · ${new Date().toISOString().slice(0, 10)}`,
  });
  return { ...result, fileName: modpackPackFileName(pack.meta.id, mcVersion) };
}
```

```tsx
import { useState } from 'react';
import type { ExportResult } from '@mlf/core/export';
import { Icon } from '../components/Icon';
import { t } from '../i18n/zh-TW';
import { buildModpackPack, fetchIncludedMods, fetchModpackData } from './downloadModpack';
import { saveBlob } from './downloadPack';

type FetchImpl = NonNullable<Parameters<typeof fetchModpackData>[1]>;

interface ModpackDownloadProps {
  readonly modpackId: string;
  readonly fetchImpl?: FetchImpl;
  readonly onSave?: (result: ExportResult) => void;
}

type Phase = 'idle' | 'working' | 'error';

export default function ModpackDownload({ modpackId, fetchImpl = fetch, onSave = saveBlob }: ModpackDownloadProps) {
  const [phase, setPhase] = useState<Phase>('idle');

  const download = async () => {
    setPhase('working');
    try {
      const pack = await fetchModpackData(modpackId, fetchImpl);
      onSave(await buildModpackPack(pack, await fetchIncludedMods(pack, fetchImpl)));
      setPhase('idle');
    } catch (err) {
      if (import.meta.env.DEV) console.error('modpack download failed', err);
      setPhase('error');
    }
  };

  return (
    <div className="flex flex-col items-start gap-3">
      <button type="button" className="btn btn-primary" disabled={phase === 'working'} onClick={() => void download()}>
        {phase === 'working' ? t.download.working : <><Icon name="download" />{t.modpackPage.download}</>}
      </button>
      {phase === 'error' && (
        <p role="alert" className="flex w-full flex-wrap items-center gap-x-2 text-sm text-danger">
          {t.download.failed}
          <button type="button" className="link inline-flex min-h-11 items-center" onClick={() => void download()}>{t.download.retry}</button>
        </p>
      )}
    </div>
  );
}
```

```ts
const indexSchema = z.object({
  version: z.literal(1),
  modpacks: z.array(z.object({
    id: z.string().refine(isValidModpackId, { message: '整合包 id 不合法' }),
    name: z.string().min(1),
    nameZh: z.string().nullable(),
    kubejs: z.object({ total: z.number().int().nonnegative() }).nullable(),
  })),
});

type FetchImpl = (url: string) => Promise<Pick<Response, 'ok' | 'status' | 'json'>>;

/** 網站上有 KubeJS 文字可翻的整合包 */
export async function fetchModpackIndex(fetchImpl: FetchImpl = fetch): Promise<ModpackOption[]> {
  const res = await fetchImpl(MODPACK_INDEX_API);
  if (!res.ok) throw new Error(`Modpack index HTTP ${res.status}`);
  const body = indexSchema.parse(await res.json());
  return body.modpacks.filter((p) => (p.kubejs?.total ?? 0) > 0).map(({ id, name, nameZh }) => ({ id, name, nameZh }));
}
```

```tsx
import { useEffect, useId, useState } from 'react';
import { fetchModpackData, type ModpackPayload } from '../../islands/downloadModpack';
import { modpackDisplayName } from '../../lib/modpackSummary';
import { t } from '../i18n/zh-TW';
import { fetchModpackIndex, type ModpackOption } from '../modpack/modpackIndex';
import { toastError } from '../store/toastStore';
import { useWorkspace } from '../store/workspaceStore';

interface ModpackLoaderProps {
  /** 必須是穩定參考；預設讀取 /api/v1/modpacks/index.json */
  readonly loadIndex?: () => Promise<readonly ModpackOption[]>;
  readonly loadModpack?: (id: string) => Promise<ModpackPayload>;
}

const defaultLoadIndex = (): Promise<ModpackOption[]> => fetchModpackIndex();
const defaultLoadModpack = (id: string): Promise<ModpackPayload> => fetchModpackData(id);

/** 「載入網站上的整合包」；沒有可翻的整合包或清單載入失敗時不顯示 */
export function ModpackLoader({ loadIndex = defaultLoadIndex, loadModpack = defaultLoadModpack }: ModpackLoaderProps) {
  const addModpack = useWorkspace((s) => s.addModpack);
  const [options, setOptions] = useState<readonly ModpackOption[]>([]);
  const [chosen, setChosen] = useState('');
  const [busy, setBusy] = useState(false);
  const id = useId();

  useEffect(() => {
    let active = true;
    loadIndex().then(
      (list) => {
        if (active) setOptions(list);
      },
      (err: unknown) => console.error('[translator] 整合包清單載入失敗', err),
    );
    return () => {
      active = false;
    };
  }, [loadIndex]);

  if (options.length === 0) return null;
  const selected = options.some((o) => o.id === chosen) ? chosen : (options[0]?.id ?? '');

  const load = async () => {
    setBusy(true);
    try {
      await addModpack(await loadModpack(selected));
    } catch (err) {
      if (import.meta.env.DEV) console.error('load modpack failed', selected, err);
      toastError(t.modpack.loadFailed);
    } finally {
      setBusy(false);
    }
  };

  return (
    <section aria-labelledby={`${id}-title`} className="flex flex-col gap-2 rounded-sm border-2 border-line bg-surface p-3 text-sm">
      <h2 id={`${id}-title`} className="text-base font-semibold">{t.modpack.title}</h2>
      <p className="text-xs text-muted">{t.modpack.hint}</p>
      <label htmlFor={`${id}-select`} className="font-medium">{t.modpack.select}</label>
      <select id={`${id}-select`} className="input" value={selected} onChange={(e) => setChosen(e.target.value)}>
        {options.map((o) => <option key={o.id} value={o.id}>{modpackDisplayName(o)}</option>)}
      </select>
      <button type="button" className="btn btn-secondary" disabled={busy} onClick={() => void load()}>
        {busy ? t.modpack.loading : t.modpack.load}
      </button>
    </section>
  );
}
```

```ts
function translatedEntries(p: ModProject): Record<string, string> {
  return Object.fromEntries(p.entries.filter((e) => e.status !== 'obsolete' && e.target !== '').map((e) => [e.key, e.target]));

function modFiles(p: ModProject, today: string): [string, string][] {
  const active = p.entries.filter((e) => e.status !== 'obsolete');
  return [
    [`${p.modId}/mod.json`, toJson(draftModJson(p, today))],
    [`${p.modId}/en_us.json`, toJson(Object.fromEntries(active.map((e) => [e.key, e.source])))],

/** 整合包 KubeJS 專案只輸出譯文；英文原文由維護者以 add:modpack 維護 */
function kubejsPath(ref: { readonly modpackId: string; readonly ns: string }): string {

export async function buildContribution(projects: readonly ModProject[], today: string): Promise<ExportResult> {
  const zip = new JSZip();

  projects.forEach((p, i) => {
    const ref = refs[i];
    const files: [string, string][] = ref ? [[kubejsPath(ref), toJson(translatedEntries(p))]] : modFiles(p, today);
    for (const [path, text] of files) zip.file(path, text);
  });
  const modIds = projects.filter((_, i) => !refs[i]).map((p) => p.modId);
  zip.file('README.txt', readme(modIds, refs.flatMap((r) => (r ? [kubejsPath(r)] : []))));
```
